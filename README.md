# 📞 Telesekreter — Akıllı Zamanlanmış İletişim ve Hatırlatma

Seçtiğiniz kişilere belirlediğiniz tarih ve saatte mesaj göndermenizi, toplu mesaj hazırlamanızı, hatırlatma ve doğum günü takibi yapmanızı sağlayan Android öncelikli kişisel iletişim asistanıdır.

> "Bir kez planlayın, Telesekreter zamanı geldiğinde sizin yerinize hatırlatsın."

## ✨ Özellikler

- ⏰ Zamanlanmış mesaj (bekliyor / gönderildi / başarısız / iptal edildi durumları)
- 👥 Rehberden kişi ve grup seçerek toplu mesaj
- 🔔 Hatırlatmalar ve doğum günü takibi
- 📞 Belirlenen zamanda arama planlama
- 🇹🇷 Sade, Türkçe ve yaşça büyük kullanıcılar için kolay arayüz

## 🛠️ Teknolojiler

- Native Android (Kotlin, Gradle)
